# IR情報の信頼性監査・独立情報源の追加（2026-09-21）

## 到達点

**EDINETとそれ以外の寄与を同程度にする目標は未達。**
件数を合わせるために確認基準を緩めたり、既存の正しいEDINET関係を間引いたりはしていない。

集計対象は、全体図に載せられる上場企業間の `confirmed` 関係。同じ企業対・関係タイプは一つに統合し、同じ情報源のURLや根拠が複数あっても1件と数える。両方の裏付けがある関係は重複区分として明示する。公表資料に記載された時点の関係であり、現在までの継続を一律に保証するものではない。

| 指標 | 監査前の集計 | 今回の集計 |
|---|---:|---:|
| EDINETの裏付けあり | 10,851 | 10,059 |
| EDINET以外の裏付けあり | 253 | 5,162 |
| 両方の裏付けあり | 97 | 3,642 |
| EDINETのみ | 10,754 | 6,417 |
| EDINET以外のみ | 156 | 1,520 |

現在の「その他 / EDINET」は **51.3%**。同数までは4,897件分の差がある。
監査前は有報転載を独立資料と区別していなかったため、単純な追加件数だけの比較ではない。
非上場を含む全関係ではEDINET 87,463件、その他7,247件、両方4,257件。

## IR抽出の監査

従来のIR抽出3,642行、参照URL1,498件を取得して本文照合した。

| 本文照合 | 行数 |
|---|---:|
| 正規化後の抽出根拠文字列を確認 | 1,149 |
| 文字列を確認できず | 2,417 |
| 取得失敗 | 39 |
| 根拠が短すぎる | 37 |

空白・句読点・文字幅を正規化した照合である。不一致は要約、ページ更新、PDF抽出の限界でも起こるため、捏造や関係不存在を意味しない。一致しても当事者、関係分類、方向、現在の継続、サイト運営者の同一性を保証しない。

本文照合と従来の意味・方向のルールを両方通過したIR行は389行。取り込み対象3,568行のうち3,179行は要確認。複数行が同一関係に統合されるため、行数は関係数ではない。

修正した問題：

- 本文で確認できない抽出根拠は、単独で関係を確定させない。
- 英文社名の先頭語が同じだけで別法人を同一視しない。
- 日本語の濁点・半濁点を保持し、「プラス／ブラス」「エヌビーシー／エヌピーシー」を別名として扱う。既存EDINET関係の件数にもこの照合修正が反映されている。
- 有限会社・合同会社等を、同名の上場株式会社に自動統合しない。
- 同じ正式名・英語名が複数銘柄に対応する場合、登録順で銘柄を決めない。法人を特定できない関係は要確認として表示する。
- 大株主の所在地を照合し、アスカ、シード、TOA、ニットーの同名別法人への誤接続を修正した。実際の非上場株主との関係は保持した。
- 新光商事・レスターの資本業務提携は2026年5月15日の終了発表に基づき過去の関係に変更した。株式保有の記録とは区別した。
- 製品採用・納入だけでは「連結売上10%以上の主要販売先」と判定しない。
- 合弁出資の出資先と共同出資者を混同しない。従来のIR抽出では対象法人の裏付けが不足するものを要確認にする。
- EDINETの役員兼任にも確認を適用し、顧問・相談役や執行役員のみの記載を、取締役・監査役・法定の執行役の兼任と区別する。
- 同じURLに不一致の抜粋と一致する抜粋がある場合、重複排除によって一致の根拠が失われないようにする。
- 企業サイトに掲載された有価証券報告書は `origin: edinet_republication` とし、寄与度ではEDINETに含める。

出典種別と抽出内容の信頼性は別に扱う。画面には本文照合、照合日、AIによる個別照合、根拠単位の要確認を表示する。原文の引用部分は公開JSONに含めない。

## 追加した情報

最初の調査では1,792社のURL候補を調査し、1,672社から計10,555ページを取得。その後、追加の役員・株主ページ、企業公式のガバナンス報告書、公式ニュースを調査。調査は継続中。URL候補はWikidataの公式サイト項目を入口にしたが、それだけで正しい企業サイト・関係とは判定しない。

企業公式サイト・発表資料から5,508件の確認記録を追加した。これは重複関係の裏付けも含む出典記録数であり、新規エッジ5,508本という意味ではない。

- 株主表：1,311記録。表の当事者と基準日を確認し、記名株主として取り込む。比率の定義が不明な数値を既存値に上書きしない。
- 役員紹介・株主総会資料：2,910記録。人物と現在の兼職を個別に照合した2,287記録と、同じ資料・人物・時点の確認済み役職から生成した623記録。略歴に社名が出るだけの退任者は採用しない。
- 公式取引先一覧：507記録。新タイプ「取引先（公式掲載）」で表し、売買の方向・売上10%以上・継続取引を推定しない。同じ企業対に確認済みの取引関係がある場合は重複追加を避けた。
- 子会社・関連会社：29記録。光通信の公式株主総会資料の関係会社表を追加。同名の上場会社と取り違えていたニックスは、所在地を付した実際の非上場法人に訂正。
- 取引金融機関：144記録。会社概要の銀行一覧を根拠にし、借入残高・主要借入先・メインバンクとは区別する。
- 主要仕入先：27記録。公式サイトの明示的な仕入先一覧を根拠にする。
- 提携・共同開発等：209記録。上場親会社が発表していても、実際の当事者が子会社なら子会社のまま記録する。合意・予定と実行済みを区別する。

- 公式導入事例：371記録・354関係。サイボウズ、Sansan、ラクス、OBC、BIPROGY、日立、リコー、マネーフォワード、クラウドサイン、HENNGE、ウイングアーク、ネオジャパン、テラスカイ、サイエンスアーツの公式事例を確認。「製品・サービス導入」として、直接契約や現在の利用継続、売上比率を推定せず、製品名と確認できた情報時点を表示する。同名別法人、子会社だけの導入、本文未取得の事例は除外。
- 統合報告書：株主表36記録と役員兼任17記録を上記内数として追加。法定の半期報告書を独立資料に数えない。
- セレス傘下のCoinTrade運営会社マーキュリーと、上場する不動産情報会社マーキュリー（5025）の誤同定を訂正。上場企業間の誤った親子・役員兼任関係を除外し、実際の非上場子会社への関係を記録した。

具体例：

- [サーバーワークス・G-genとBIPROGYの業務提携](https://www.serverworks.co.jp/news/20260907_swx_g-gen_biprogy.html)
- [FRONTEOとカイオムの共同研究](https://www.fronteo.com/news/pr/20260903?hsLang=ja)
- [アイシンと日本電子の共同開発](https://www.aisin.com/jp/news/2026/010693.html)

すべてのURL、資料のハッシュ（取得できたもの）、日付、照合者、関係の当事者は `data_raw/official_relations.json` に保存。個別照合者は `codex_primary_source_review`、確認済み役職からの生成は `reviewed_same_document_offices` であり、人間による確認と称していない。

## 株主総会資料の追加監査

726社の資料を取得し、役員兼任候補915件を個別に確認した。候補者の新任予定、過去の略歴、隣の人物の兼職、退任注記を区別して採否を記録。資料の基準日が不明なものは不明として保持する。

退任・退任予定は人物単位で訂正する。同じ企業対を結ぶ別の現任者がいる場合は関係全体を消さず、退任者の根拠だけを現在の寄与集計から除く。退任予定しか確認できないものは現任確認待ちとし、予定日を実際の退任日と断定しない。DTS、ニックス、ベーシックの同名別法人への誤接続は所在地・事業・役員を照合して除外した。

追加154社の資料から兼任候補237件を確認し、199件を個別照合記録として採用した。退任予定の記録は取り込んだ場合も人物別の訂正を優先し、現任の寄与から除外する。

[光通信の公式総会資料](https://www.hikari.co.jp/assets/pdf/ir/250605_2.pdf)で、上場親会社「株式会社光通信」と有価証券保有子会社「光通信株式会社」を区別した。法人格の前後を保った完全一致を追加し、子会社の株式保有を親会社の直接保有に置き換えない。既存の公式株主表12記録も実際の子会社に修正した。

追加の総会資料・公式役員紹介・ガバナンス報告書から現任の兼職と記名株主を照合した。株式の種類が優先株式の場合は説明に明記し、普通株式の比率へ読み替えない。富士興産の旧資料を新設持株会社の直接の株主表として転用しない。

コンドーテック傘下の足場工事会社フコクと上場ゴム製品メーカーのフコク（5185）、GMOグローバルサインの旧商号アイルと上場会社アイル（3854）の取り違えを訂正した。前者の実際の非上場子会社との関係は保持した。追加で確認した退任・退任予定も人物単位で訂正した。

## 調べた追加情報源と採用上の条件

| 情報源 | 信頼できる範囲・今回の扱い |
|---|---|
| 企業公式の株主表・役員紹介・会社概要 | 当該企業が公表した事実の一次資料。法人・時点・役職・表の意味を照合して採用。更新日不明は不明のまま表示 |
| 企業公式プレスリリース | 当事者による発表の一次資料。親子の混同、予定の実行済み扱い、第三者同士の記述を除外して採用 |
| [NEDO](https://www.nedo.go.jp/)・[JSTの発表](https://www.jst.go.jp/pr/press-2025.html) | 採択・研究実施の一次資料。大きな事業やコンソーシアムの参加企業同士をすべて直接提携の線で結ぶことはしない。今回の確定データには未追加 |
| [特許庁の公報データ](https://www.jpo.go.jp/system/laws/sesaku/data/download.html) | 出願等の事実に適する。大量データの取得手続、法人識別、関係の時点の検証が別途必要。今回未追加 |
| [USPTO PatentsView](https://www.uspto.gov/ip-policy/economic-research/patentsview) | USPTOの研究用加工データで、公式原簿そのものではない。現在の提携や現在の権利者を直接示すものではない |
| [PatentsViewの2024年末版アーカイブ](https://zenodo.org/records/15783125) | 出願人データ6,010,194行を試験分析。現在の企業英文名との厳密な正規化一致で208企業対の候補。ただし同名法人・旧社名・権利移転・年代・アーカイブの由来の追加検証が必要。候補を確定関係に取り込んでいない |

特許候補を現在の業務提携に読み替えたり、同一事業の参加者から無条件に企業対を作って寄与度を水増ししたりはしない。IR候補と役員紹介にも未確認のものが残っている。

## 再現方法

追加依存は `requirements-audit.txt`。取得本文・PDF・引用部分・候補一覧は無視対象の `outputs/` に保存し、Git管理するのは事実と検証メタデータのみ。

```sh
python pipeline/audit_ir_sources.py --out outputs/ir-source-audit --checks-out pipeline/data_raw/ir_source_checks.json
python pipeline/discover_issuer_sources.py --out outputs/issuer-source-research
python pipeline/build_masters.py
python pipeline/make_viz_data.py
python pipeline/source_contribution.py pipeline/data_processed/masters/M5_company_relations.json
python3 -m unittest discover -s pipeline/tests
npm test
npm run build
```

`discover_issuer_sources.py` は候補発見用であり、自動承認や無人での件数目標達成を行うものではない。基準を満たした事実だけを `official_relations.json` に追加して再生成する。

## 導入事例の法人・提供主体の照合

導入支援は製品自体の開発元と区別し、製品名に「移行支援」「構築支援」など実際のサービスを明記した。リコージャパンやユニアデックスだけが提供したサービスを、上場親会社の取引として置き換えない。リコーブランドの製品・クラウドについては、メーカー公式発表でも提供主体を確認して製品採用の関係として取り込んだ。

マネーフォワードの導入事例に掲載される航空保安の「ジェイ・エス・エス」は、上場の水泳教室運営会社JSS（6074）とは別法人のため除外。掛け払いなど子会社が提供するサービス、親会社自身の採用を確認できない子会社事例、共同実証だけの段階、汎用ページへのリダイレクトも今回の導入記録から除いた。

公式会社概要の追加巡回から取引先151記録・仕入先2記録を追加。NTTドコモの改行断片「NTT」、道路舗装会社NIPPOと日邦産業（9913）、プライズ商品のアミューズと上場の芸能事務所（4301）、企業グループ名と持株会社の取り違えを候補段階で除外した。パレモ子会社の取引一覧をパレモ・ホールディングスへ置き換えることも避けた。

今回の追加では、製品一覧のタグが現在の名称に更新されていても、導入時点の本文で確認できた製品名を優先した。導入構想・構築途中だけの事例は保留。ペット専門店コジマと家電量販店、IT会社ジェイエスピーと素材メーカー、家電企画販売のサンコーと精密部品メーカーの同名誤接続を除外した。銀行一覧では三菱UFJ等の省略表記を上場金融持株会社に読み替えず、非上場ラ・アトレを上場親会社LAホールディングスの取引先として扱わない。
